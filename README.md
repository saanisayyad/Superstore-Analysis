# Superstore Analysis

Business sales and profitability analysis using **SQL** and **Power BI** on Superstore data.

## Highlights
- Sales, profit, orders, and customer analysis
- Category, sub-category, region, and product performance
- Customer revenue, repeat purchases, and lifetime value
- Monthly sales and profit trends
- Power BI dashboard for interactive insights

## Files
- `Superstore.csv` — source dataset
- `Superstore.sql` — SQL analysis queries
- `Superstore.pbix` — Power BI dashboard
- `Superstore_Dashboard.pdf` — dashboard export

## Tools
**SQL · MySQL · Power BI**
