# Superstore Analysis

Business sales and profitability analysis using **SQL** and **Power BI** on the Superstore dataset.

## Project Overview
This project analyzes sales transactions to understand revenue, profitability, customer performance, product trends, regional performance, and business growth over time. SQL is used to answer key business questions, while Power BI is used to build an interactive dashboard.

## Key Analysis
- Total sales, profit, orders, and customers
- Average order value
- Sales by category and sub-category
- Regional revenue performance
- Top products by revenue and profit
- Loss-making products
- Top and most profitable customers
- Repeat customer analysis
- Monthly revenue and profit trends
- Customer ranking by revenue
- Top-performing products within each category
- Category revenue contribution
- Customer Lifetime Value (CLV)
- Revenue concentration among high-value customers

## Files
- `Superstore.csv` — source dataset
- `Superstore.sql` — SQL queries for business analysis
- `Superstore.pbix` — Power BI dashboard
- `Superstore_Dashboard.pdf` — exported dashboard

## Tools & Technologies
**SQL · MySQL · Power BI**

## Business Questions
The SQL analysis focuses on practical questions such as which categories and products generate the most revenue, which products create losses, who the most valuable customers are, how sales change over time, and how revenue is distributed across the customer base.

## Outcome
The project demonstrates an end-to-end business intelligence workflow: analyzing transactional data with SQL and transforming the results into an interactive Power BI dashboard for decision-making.
